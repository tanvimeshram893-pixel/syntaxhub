🏠 House Price Prediction using Machine Learning


📌 Overview
This project focuses on predicting house prices using Machine Learning techniques. It uses the California Housing Dataset to train a regression model that estimates house prices based on various features such as income, population, and location.


 🎯 Problem Statement
The goal of this project is to build a machine learning model that can accurately predict house prices based on input features.


🎯 Objectives
- Analyze housing dataset  
- Perform data preprocessing  
- Build a Linear Regression model  
- Evaluate model performance  
- Predict house prices  

📂 Dataset
- Dataset: California Housing Dataset  
- Source: Scikit-learn & Kaggle  

Features:
- Median Income  
- House Age  
- Average Rooms  
- Population  
- Latitude & Longitude  

⚙️ Technologies Used
- Python  
- Jupyter Notebook / Google Colab  
- NumPy  
- Pandas  
- Matplotlib  
- Seaborn  
- Scikit-learn  

🔍 Project Workflow
1. Data Loading  
2. Data Preprocessing  
3. Exploratory Data Analysis (EDA)  
4. Feature Selection  
5. Train-Test Split  
6. Model Training (Linear Regression)  
7. Model Evaluation (RMSE, R² Score)  
8. Prediction
